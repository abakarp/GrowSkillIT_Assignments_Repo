 solve below questions using while loop

1)Print every alternate uppercase letter

Output:
A C E G I ... Y

Solution:

package dailyassigments;

public class Assignment5_AlternateUppercaseLetter {

	public static void main(String[] args) {
		
		char ch = 'A';
		while(ch<='Z')
		{
			System.out.print(ch+" ");
			ch+=2;
		}
	}

}

Output:
A C E G I K M O Q S U W Y

2)Print ASCII values of A to Z

Output:
A = 65
B = 66
...
Z = 90

Solution 

package dailyassigments;

public class Assignment5_ASCII_ValuesA_Z {

	public static void main(String[] args) {
		
		char ch ='A';
		while(ch<='Z') {
			System.out.println(ch + " = " + (int) ch);
			ch++;
		}
	}
}

Q1. Remove Duplicate Characters
Write a Java program to remove duplicate characters from a string while preserving the order of their first occurrence.

Example:

Input:  programming
Output: progamin

Solution:

package weeklyassigments;

import java.util.*;
public class Assignment7_String_RemoveDuplicateCharacters {

	public static void main(String[] args) {

        String input = "programming";

        Set<Character> set = new LinkedHashSet<>();

        for (char ch : input.toCharArray()) {
            set.add(ch);
        }

        StringBuilder result = new StringBuilder();

        for (char ch : set) {
            result.append(ch);
        }

        System.out.println("Original String : " + input);
        System.out.println("After Removing Duplicates : " + result);

	}
}

Output:
Original String : programming
After Removing Duplicates : progamin

2)Sum of Numbers in a String

Given a string containing numbers separated by commas, calculate the sum using Wrapper classes.

Example:

Input:
"10,20,30,40"

Output:
100

Solution:

package weeklyassigments;

public class Assignment7_String_WrapperClass_SumOfDigits {

	public static void main(String[] args) {
		String str="10,20,30,40";
		
		String[] numbers =str.split(",");
		int sum=0;
		
		for(String num:numbers)
		{
			sum+=Integer.parseInt(num);
		}
		
		System.out.println("Sum of numbers = "+sum);
	}
}

Q3. Check if Two Strings are Anagrams

Write a Java program to determine whether two strings are anagrams of each other. Ignore spaces and character case.

Example:

Input:
listen
silent

Output:
Anagram

Solution:

package weeklyassigments;

import java.util.Arrays;

public class Assignment7_String_Anagrams {
	
	public static boolean isAnagram(String s1, String s2)
	{
		if(s1.length()!=s2.length())
		{
			return false;
		}
		
		char[] ch1=s1.toCharArray();
		char[] ch2=s2.toCharArray();
		
		Arrays.sort(ch1);
		Arrays.sort(ch2);
		
		return Arrays.equals(ch1, ch2);
			
	}
	
	public static void main(String[] args) {
		String input1= "listen";
		String input2= "silent";
		
		// Remove spaces and convert to lowercase
		input1=input1.replaceAll("\\s", "").toLowerCase();
		input2=input2.replaceAll("\\s", "").toLowerCase();

		if(isAnagram(input1,input2))
		{
			System.out.println("Anagram");
		}
		else
		{
			System.out.println("Not Anagram");
		}
	}

}


Output:
Anagram

Q5)Find Missing Numbers

Given a List<Integer> containing numbers from 1 to N with some numbers missing, find all the missing numbers.

Example:

Input:
[1, 2, 4, 6, 7, 9]
N = 10

Output:
[3, 5, 8, 10]

Solution:

package weeklyassigments;

import java.util.*;

public class Assignment7_FindMissingNumbers {

	public static void main(String[] args) {
		int n=10;
		List<Integer> numbers=Arrays.asList(1, 2, 4, 6, 7, 9);
		
		List<Integer>missing = new ArrayList<>();
		
		for(int i=1;i<=n;i++) {
			if (!numbers.contains(i))
			{
				missing.add(i);
			}
		}
	
		System.out.println(missing);

	}

}

Output:
[3, 5, 8, 10]

Q8)Increase Salary by 10%

Using Java Streams:

Create a new list where each employee's salary is increased by 10%.
Display employee name and updated salary.
Do not modify the original list.

Expected Output:

Rahul - 55000
Priya - 44000
Amit - 82500
Neha - 71500
Aman - 99000

Concepts: map(), toList()

Solution:

package weeklyassigments;

import java.util.*;

class Employee1
{
	private int id;
	private String name;
	private String department;
	private int salary;
	
	public Employee1(int id, String name, String department, int salary) {
		super();
		this.id = id;
		this.name = name;
		this.department = department;
		this.salary = salary;
	}

	public int getId() {
		return id;
	}

	public void setId(int id) {
		this.id = id;
	}

	public String getName() {
		return name;
	}

	public void setName(String name) {
		this.name = name;
	}

	public String getDepartment() {
		return department;
	}

	public void setDepartment(String department) {
		this.department = department;
	}

	public int getSalary() {
		return salary;
	}

	public void setSalary(int salary) {
		this.salary = salary;
	}
}

public class Assignment7_StreamAPI_EmpSalaryIncreased10 {

	public static void main(String[] args) {
		
		Employee1 e1 =new Employee1(301,"Rahul","IT",50000);
		Employee1 e2 =new Employee1(302,"Priya","HR",40000);
		Employee1 e3 =new Employee1(303,"Amit","IT",75000);
		Employee1 e4 =new Employee1(304,"Neha","Finance",65000);
		Employee1 e5 =new Employee1(305,"Aman","IT",90000);
		
		List<Employee1> list = new ArrayList<Employee1>();
		list.add(e1);
		list.add(e2);
		list.add(e3);
		list.add(e4);
		list.add(e5);
		
		List<Employee1> updatedEmployees = list.stream()
				.map(e->new Employee1(
				e.getId(),
				e.getName(),
				e.getDepartment(),
				(int) (e.getSalary() * 1.10)
				)).toList();

		updatedEmployees.forEach(e ->
        System.out.println(
                e.getName() + " - " + e.getSalary()
        			)
				);
	}

}


Output:
Rahul - 55000
Priya - 44000
Amit - 82500
Neha - 71500
Aman - 99000

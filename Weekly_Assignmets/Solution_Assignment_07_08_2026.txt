Q1. Check Anagram
Write a Java program to check whether two given strings are anagrams of each other.

Example:
Input: "listen", "silent"
Output: Anagram

Solution:
package weeklyassigments;

import java.util.Arrays;

public class Assignment8_Strings_Anagrams {
	
	public static boolean isAnagram(String s1, String s2)
	{
		if(s1.length()!=s2.length())
		{
			return false;
		}
		
		char[] ch1=s1.toCharArray();
		char[] ch2=s2.toCharArray();
		
		Arrays.sort(ch1);
		Arrays.sort(ch2);
		
		return Arrays.equals(ch1, ch2);
			
	}

	public static void main(String[] args) {
		String input1= "listen";
		String input2= "silent";
		
		// Remove spaces and convert to lowercase
		input1=input1.replaceAll("\\s", "").toLowerCase();
		input2=input2.replaceAll("\\s", "").toLowerCase();

		if(isAnagram(input1,input2))
		{
			System.out.println("Anagram");
		}
		else
		{
			System.out.println("Not Anagram");
		}
		

	}

}

output:
Anagram

Q3. Find First Non-Repeating Character
Write a Java program to find the first character in a string that does not repeat.

Example:
Input: "swiss"
Output: w

Solution

package weeklyassigments;

import java.util.*;

public class Assignment8_First_Non_Repeating_Character {
	
	public static Character findFirstNonRepeating(String str) {

        Map<Character, Integer> map = new LinkedHashMap<>();

        // Count frequency of each character
        for (char ch : str.toCharArray()) {
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        // Find first character with frequency 1
        for (Map.Entry<Character, Integer> entry : map.entrySet()) {
            if (entry.getValue() == 1) {
                return entry.getKey();
            }
        }

        return null;
    }

	public static void main(String[] args) {
		 String input = "swiss";

	        Character result = findFirstNonRepeating(input);

	        System.out.println("First Non-Repeating Character: " + result);

	}

}

Output: w

Q4. File Handling â€“ Word Frequency

Write a Java program to read a text file and find the frequency of each word present in the file.

Requirements:

Read the contents of a .txt file.
Count how many times each word occurs.
Ignore case differences (Java and java should be treated as the same word).
Display each word along with its frequency.

Example file content:

Java is easy.
Java is powerful.
Java is easy to learn.

Expected output:

java : 3
is : 3
easy : 2
powerful : 1
to : 1
learn : 1

Solution:

package weeklyassigments;

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.util.*;

public class Assignment8_File_Handling_Frequency_Of_Each_Word {

public static void main(String[] args) throws Exception {

	
	String filePath = "D:\\Purnima_Work\\GrowSkillIT\\GrowSkillIt_Weekly_Assignments\\Assignment_07_08_2026_frequency of each word.txt";

    Map<String, Integer> wordCount = new HashMap<>();

    try (BufferedReader br = new BufferedReader(new FileReader(filePath))) {

        String line;

        while ((line = br.readLine()) != null) {

            // Convert the line to lowercase
            line = line.toLowerCase();

            // Remove punctuation
            line = line.replaceAll("[^a-zA-Z0-9 ]", "");

            // Split line into words
            String[] words = line.split("\\s+");

            for (String word : words) {

                if (!word.isEmpty()) {
                    wordCount.put(
                        word,
                        wordCount.getOrDefault(word, 0) + 1
                    );
                }
            }
        }

        // Display word frequency
        for (Map.Entry<String, Integer> entry : wordCount.entrySet()) {
            System.out.println(
                entry.getKey() + " : " + entry.getValue()
            );
        }

    } catch (IOException e) {
        System.out.println("Error reading file: " + e.getMessage());
    }		
		
  }

}

Output:

java : 3
powerful : 1
learn : 1
is : 3
to : 1
easy : 2
